# Business Requirements

## Project Objective

Analyze sales, customer behavior, product performance, and user engagement data to generate actionable business insights and support data-driven decision-making.

---

# Sales Analysis

1. What is the total revenue generated?
2. How many orders were placed?
3. What is the average order value (AOV)?
4. Which products generate the highest revenue?
5. Which categories generate the highest revenue?
6. Which brands generate the highest revenue?
7. What are the monthly revenue trends?
8. What are the monthly order trends?

---

# Customer Analysis

1. Who are the top customers by spending?
2. Which customers place the highest number of orders?
3. What is the average spending per customer?
4. Which cities generate the highest revenue?
5. Which cities have the highest number of customers?
6. How many new users register each month?
7. What is the customer growth trend over time?

---

# Product Analysis

1. Which products are sold most frequently?
2. Which products generate the highest sales quantity?
3. Which products have the highest average ratings?
4. Which products receive the most reviews?
5. Which categories have the highest average ratings?
6. Which brands have the highest average ratings?

---

# Order Analysis

1. What is the distribution of orders by status?
2. What percentage of orders are cancelled?
3. Which month records the highest number of orders?
4. Which month generates the highest revenue?

---

# User Behavior Analysis

1. Which products receive the highest number of views?
2. Which products are added to cart most frequently?
3. Which products are added to wishlist most frequently?
4. What is the distribution of user actions by event type?
5. Which products have high views but low purchases?
6. Which products have high cart activity but low purchases?

---

# Advanced Business Analysis

1. Identify customers who registered but never placed an order.
2. Identify products that were never purchased.
3. Find repeat customers who placed multiple orders.
4. Calculate each product's contribution to total revenue.
5. Compare product engagement versus actual purchases.

---

# Deliverables

- Python Data Cleaning
- SQL Analysis
- Exploratory Data Analysis (EDA)
- Forecasting
- Power BI Dashboard
- Business Insights Report
- Strategic Recommendations

# E-Commerce Sales Intelligence & Customer Analytics Dashboard

## Project Overview

This project focuses on analyzing an e-commerce business dataset to
understand sales performance, customer behaviour, product performance,
and user engagement.

The goal of this project is to transform raw e-commerce data into
meaningful business insights using data cleaning, exploratory data
analysis, SQL analysis, and an interactive Power BI dashboard.

------------------------------------------------------------------------

## Business Objectives

The project answers important business questions:

### Sales Analysis

-   What are the overall sales and revenue trends?
-   Which categories and brands generate the highest revenue?
-   How do monthly sales and orders perform?

### Product Analysis

-   Which products are sold most frequently?
-   Which products generate the highest quantity sold?
-   Which products have the highest ratings and reviews?
-   Which products contribute most to revenue?

### Customer Analysis

-   Who are the top customers by spending?
-   Which customers place repeat orders?
-   Which cities generate the highest revenue?
-   How is customer growth changing over time?

### User Behaviour Analysis

-   Which products receive the highest views?
-   Which products are added to cart or wishlist most?
-   Which products have high engagement but low purchases?

# Dataset Overview

The project contains multiple tables:

## Users

Customer information and registration details.

## Products

Product details including category, brand, price and ratings.

## Orders

Transaction information and order details.

## Order Items

Product level sales information.

## Reviews

Customer feedback and ratings.

## Events

User interactions such as views, cart and wishlist actions.
